# 历史关键帧后端及冻结试验实现

这些模块不由正式 `pam_mosaic` 管线导入。它们保留信息矩阵扩展、因子测量、关键帧管理及滑窗先验，供两个对照脚本复现。内部依赖原前端特征和图像配准模块。

`test_keyframe_backend.py.txt` 是回退前通过的实验测试原文，仅用于记录；其中曾有现已撤销的关键帧管线接口测试，不属于当前自动测试集。关键帧/窗口开关不恢复。正式 CLI 现提供新的 `--backend-factors all` 全帧增强方案（`src/pam_mosaic/backend/allframe.py`），与归档的关键帧方案不同；默认 `none` 保持原流程。
