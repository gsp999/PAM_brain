# 当前大图质量改进计划

原则：任何试验使用独立输出目录；只有局部目标和未参与调参的留出区域同时改善，才替换稳定版 `outputs/frontend_only_stitched/`。

## 第一阶段：局部几何可信度（最高优先级）

1. 对已确认错位窗口回溯主要原始帧与配准边。
2. 使用闭合路径、图像证据和位姿敏感性筛选可疑边，不因单一低相关性直接改位姿。
3. 每次只修改一个因素，重新融合受影响局部块。
4. 验收同时检查：目标窗口、同一块对其余窗口、该块与其他块的接缝、全图覆盖。

当前进度：已确认 `component_074 / component_027` 顶部亮弧局部错位；整块平移会严重破坏其他区域。`842→844` 与 `844→846` 虽有图像和闭合冲突，但分别删除后全部接缝指标变化都不足 0.01，证明现有鲁棒位姿图已基本压制它们。下一步不再直接删边，应把该异常视为可能的局部非刚性变化、采集时序差异或多条小误差共同作用；没有新的独立证据前保持稳定几何。

跨扫描原始帧核查进一步确认两侧来自不同采集批次：455～471 为 `scan1`，843～849 为 `scan3`。119 组原始帧没有一组通过严格 SIFT 验证；以现有位姿为初值的局部相位残差中仅 4 组达到最低筛选条件，且仍有较大边缘距离。少数结果聚集在约 `(+20,-2)` 像素，另一些高响应结果却约为 `-24` 像素，不能建立唯一刚体修正。该接缝暂列为跨扫描局部不一致，不做局部平移或非刚性扭曲。

## 第二阶段：融合清晰度

在第一阶段固定可靠位姿后，再比较两级融合与单次投影。使用细血管边缘宽度、亮暗区梯度、有效覆盖和接缝重影共同验收，不使用锐化制造改善。此前单次投影收益很小，因此暂不优先替换。

## 第三阶段：强度一致性与伪影

仅在可信重叠区估计保守的块间增益和偏置，限制校正幅度；科学浮点原图保持不变，另存显示版本。亮点和扫描线只处理已确认伪影，避免误删细血管。

## 第四阶段：展示输出

生成自动裁边、透明背景和统一显示范围的展示图。这一阶段只改善观看效果，不宣称提高配准或科学准确性。

## 第五阶段：未入图数据

逐块检查剩余 218 份数据是否提供新增覆盖。只有存在可靠多帧支持且不会产生重影时才加入；不以入图数量作为主要优化目标。
