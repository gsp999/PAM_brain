## 当前稳定版（请勿误称为关键帧方案）

- 一个 `.dat` 是一个全局采集位置。MATLAB 原始矩阵为 500×1000，拆出正、返各 500×500；先做轨迹校正，在文件内部验证对齐，可信时融合，否则选较好的一向。科学强度保留浮点数；0.02～0.25 到 0～255 仅用于配准视图和预览。
- 适度滤除紧凑亮点；失败时不回退到未去噪图。前端以 SIFT/RANSAC 求初值，点到点 LM 和 Canny 边缘距离场精化；建立相邻、短间隔、外观候选关系，并对少数断开相邻关系做保守恢复。
- 连通分量内部对**逐帧位姿**做相对位姿图 LM，再先融合为局部块。选择至少 50 文件的块做块间配准、一致性检查和块级 LM，最终按权重平均融合。**当前没有关键帧选择、滑动窗口关键帧后端或“普通帧跟随关键帧”的机制。** 没有额外的几何/强度后端因子。详见 `README.md`、`src/pam_mosaic/pipeline.py`、`src/pam_mosaic/poses.py`、`src/pam_mosaic/tile_stitch.py`。
- 当前保留的结果：`outputs/frontend_only_full/` 和 `outputs/frontend_only_stitched/mosaic_001/`。大图预览是 `mosaic_preview.png`，科学数值是 `mosaic_float64.npy`。最近已完成的全量记录为处理 1301 文件，125 个局部连通分量；7 个大块组成 3050×3010 的大图，共入图 1083 文件。早期基线保留在 `outputs/lm_full/`、`outputs/lm_stitched/`。
